# Ganit Setu Student + Teacher Final

This package combines the existing Student and Teacher panels under one common entry page.

## Flow
- `index.html` -> choose Student or Teacher
- Student -> existing Student login/registration
- Teacher -> existing Teacher login/registration

## Important
- Student and Teacher code remain in separate folders.
- Existing Supabase configuration/authentication code is preserved.
- UDISE/DISE-related fields and existing backend logic are not removed in this version.
- Admin Panel is intentionally NOT included; keep the Admin repository separate.
- Keep the original Student and Teacher repositories as backups until this version has been fully production-tested.

## GitHub Pages
Upload the contents of this ZIP to a new repository and enable GitHub Pages from the repository's main branch/root. Open the published site at the repository Pages URL.
